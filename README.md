# НЦА РК — концепт редизайна

Неофициальный концепт нового сайта Национального центра аккредитации РК ([nca.kz](https://www.nca.kz/)).
Сделан в учебных целях и для портфолио. Данные в реестре демонстрационные, названия организаций вымышлены.

## Стек

- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS 4
- Три языка: `/ru`, `/kk`, `/en` (словари в `src/app/[lang]/dictionaries/`)
- Иконки: lucide-react

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000 — произойдёт редирект на `/ru`.

## Структура

```
src/
  app/[lang]/            страницы с языковым префиксом
    dictionaries/        переводы ru / kk / en
    [section]/           заглушки разделов
  components/            Header, Footer, RegistrySearch
  data/                  моковые данные реестра и новостей
  lib/i18n.ts            языки и разделы меню
  proxy.ts               редирект / → /ru
```

## Что не так с текущим сайтом (аудит, ноябрь 2026)

- Битрикс + готовый шаблон Aspro Allcorp3; около 30 jQuery-плагинов на главной.
- URL остались от демо-шаблона: законодательные акты в `/price/grunty-setki/`,
  типовые формы в `/price/zhbi-kirpich/`, приказы по субъектам в `/sales/`,
  международное сотрудничество в `/company/brands/`.
- На главной висит «ведётся наполнение сайта».
- Реестр субъектов открывается по IP-адресу без HTTPS, сведения из реестра — в Google-таблице,
  заявка — через `old.nca.kz`.
- Главная задача пользователя (проверить аккредитацию) не видна с первого экрана.
- Языковые версии на `/s2/` и `/s3/` вместо `/en/` и `/kk/`.
